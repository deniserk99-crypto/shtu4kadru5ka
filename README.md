# Discount Engine — «Штучки-Дрючки»

Учебный проект: расширяемый движок расчёта скидок для маркетплейса.

## Реализовано

- Product, CartItem, Customer, Order
- DiscountContext, AppliedDiscount, PricingResult
- 7 типов скидок
- Strategy
- Factory
- Singleton ConfigProvider
- Полиморфный PricingEngine
- Breakdown применённых скидок
- Автоматические unit-тесты

## Порядок скидок

1. 3 по цене 2
2. Процентные скидки
3. Фиксированные скидки
4. Бесплатная доставка

Внутри стадии сохраняется порядок конфигурации.

Процентный промокод конкурирует с обычной процентной скидкой на одной и той же текущей сумме. Выбирается большая денежная выгода, при равенстве — промокод. Фиксированный промокод применяется на этапе фиксированных скидок.

## Округление

Все денежные результаты округляются до копеек способом `ROUND_HALF_EVEN` (banker's rounding). Округление выполняется после каждого изменения денежной суммы.

## Промокоды

Сравнение кодов выполняется без учёта регистра. Дата окончания включительна: код действителен в день окончания. Неактивный, неизвестный или просроченный код не применяется.

## Запуск

Python 3.10+.

Запустить демонстрацию:

```bash
python main.py
```

Запустить тесты:

```bash
python -m unittest discover -s tests -v
```

## Архитектура

`PricingEngine` работает с абстракцией `DiscountStrategy` и не знает конкретные классы скидок.

`DiscountFactory` создаёт стратегии по данным конфигурации.

`ConfigProvider` реализован как Singleton и хранит конфигурацию скидок, но не состояние конкретного заказа.

Каждый тип скидки находится в отдельном классе.
